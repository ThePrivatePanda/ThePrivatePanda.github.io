Meddler in development

solo · design + build · active

A deterministic simulator of a fictional world — countries with economies, currencies, trade, leaders, wars, and disasters on a daily tick loop. History can be paused, scrubbed, and rewound; any headline traces back through its chain of causes; and intervening forks the timeline, showing the future that was going to happen beside the one just caused. Forks replay the parent’s exact RNG state, so every divergence is attributable to the intervention alone.

Python · event-sourced engine · WebSocket bridge · HTML/JS · Hypothesis property tests

Spin Drift — GPS-denied drone navigation

internship · Nov 2025 – May 2026 · code under NDA

A from-scratch visual-inertial odometry pipeline in C++23 that turns stereo cameras and an IMU into a live pose estimate for an autonomous drone flying without GPS. Hand-written pyramidal Lucas-Kanade stereo tracking, MAGSAC++ outlier rejection, and IMU pre-integration on SO(3); the pose stream is framed as MAVLink v2 by hand (CRC, ENU-to-NED) to keep the PX4 flight-controller link dependency-free.

C++23 · OpenCV · PX4 / MAVLink v2 · Gazebo SITL · Jetson AGX Orin

StateLens — path-exhaustive fuzzing infrastructure

internship · Summer 2025 · code under NDA

Compiler and program-analysis infrastructure for a fuzzer that aims to exercise substantially every execution path through firmware and embedded targets: an LLVM pass that rewrites program IR into a canonical deterministic form, a C++ constraint-graph path solver served over a socket, a customized AFL++ fork, and a Guix channel pinning the whole toolchain for bit-identical team-wide builds.

LLVM / C++ · Clang · AFL++ · Guix · Answer Set Programming

SPINE — covert short-range radio

MIT Lincoln Laboratory · SOCOM Ignite · Networks Lead · Sep 2024 – Apr 2025

A secure short-range radio system for US Navy field operators, built to trade range for a minimal RF signature. Designed the custom communication protocol — framing sized to benchmarked NRF24 throughput — with one stack running across Raspberry Pi, Teensy, and RP2040/Pico, plus HINT, a zero-interaction USB configuration loader for operators who cannot type under field stress. Delivered a working demonstration across two hardware generations.

custom RF protocol · NRF24L01 · Raspberry Pi · Teensy · RP2040 · MicroPython

A structured logging library for Python: coloured, column-aligned output that drops into a project with almost no configuration. Writes ANSI codes directly and batches file writes on a background thread, so heavy logging stays cheap. MIT licensed and typed.

Python · ANSI · threading · py.typed

When to Compute in Space

with Dr. Gregory Falco · Cornell · Fall 2025 – Spring 2026

Where should a computational task run — onboard flight computer, orbital data center, ground station, or terrestrial cloud — when latency, cost, energy, radiation, security, and reliability all conflict? Reframed a single-utility compute-placement model as multi-objective trade-space search on the tier simplex, and built the two-stage framework, both mission evaluators, and all six benchmarked optimizers behind the resulting paper (under review, below).

Python · NSGA-II · SPEA2 · MOEA/D · MOPSO · ε-constraint

Automated Functional Movement Screen

LISC, Dr. Silvia Ferrari · Cornell · Spring 2026

The analysis core of a VR posture-correction system driven by motion-diffusion and VLM feedback. From raw motion-capture quaternions, derives joint angles, ranges of motion, and clearances to grade the seven FMS physical-therapy exercises, and scores form 0–3 with a declarative rule interpreter whose guard operands reject biomechanical compensations. Shipped as an installable package with a CLI.

Python · XSens MVNX · NumPy · quaternion kinematics
