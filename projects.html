Featured 05

Meddler in development

solo · design + build · active

A deterministic simulator of a fictional world — countries with economies, currencies, trade, leaders, wars, and disasters on a daily tick loop. History pauses, scrubs, and rewinds; any headline traces back through its chain of causes; and intervening forks the timeline, showing the future that was going to happen beside the one just caused. Forks replay the parent’s exact RNG state, so every divergence is attributable to the intervention alone — the architecture (pure event-sourced engine, thin protocol, dumb view) is the point.

Python · event-sourced engine · WebSocket bridge · HTML/JS · Hypothesis property tests

Spin Drift — GPS-denied navigation

internship · Nov 2025 – May 2026 · code under NDA

A from-scratch visual-inertial odometry pipeline in C++23: stereo cameras and an IMU in, live pose out, streamed to a PX4 flight controller as hand-framed MAVLink v2 (CRC, ENU-to-NED) so the link carries no dependencies. Pyramidal Lucas-Kanade stereo tracking, MAGSAC++ outlier rejection, IMU pre-integration on SO(3).

C++23 · OpenCV · PX4 / MAVLink v2 · Gazebo SITL · Jetson AGX Orin

SPINE — covert short-range radio

MIT Lincoln Laboratory · SOCOM Ignite · Networks Lead · 2024–25

A secure short-range radio for US Navy field operators, trading range for a minimal RF signature. Designed the custom protocol — framing sized to benchmarked NRF24 throughput — with one stack across Raspberry Pi, Teensy, and RP2040, plus HINT, a zero-interaction USB configuration loader for operators who cannot type under field stress. Demonstrated across two hardware generations.

custom RF protocol · NRF24L01 · Raspberry Pi · Teensy · RP2040 · MicroPython

StateLens — path-exhaustive fuzzing

internship · Summer 2025 · code under NDA

Compiler and analysis infrastructure for a fuzzer that aims to exercise substantially every execution path through firmware: an LLVM pass rewriting program IR into a canonical deterministic form, a C++ constraint-graph path solver served over a socket, a customized AFL++ fork, and a Guix channel pinning the toolchain for bit-identical team-wide builds.

LLVM / C++ · Clang · AFL++ · Guix · Answer Set Programming

A structured logging library for Python: coloured, column-aligned output that drops into a project with almost no configuration. Writes ANSI codes directly and batches file writes on a background thread, so heavy logging stays cheap. MIT licensed and typed.

Python · ANSI · threading · py.typed

Research 04

When to Compute in Space

with Dr. Gregory Falco · Cornell · 2025–26

Where should a computational task run — onboard flight computer, orbital data center, ground station, or terrestrial cloud — when latency, cost, energy, radiation, security, and reliability all conflict? Reframed a single-utility model as multi-objective trade-space search on the tier simplex; built the two-stage framework, both mission evaluators, and all six benchmarked optimizers behind the paper below.

Python · NSGA-II · SPEA2 · MOEA/D · MOPSO · ε-constraint

Automated Functional Movement Screen

LISC, Dr. Silvia Ferrari · Cornell · Spring 2026

The analysis core of a VR posture-correction system driven by motion-diffusion and VLM feedback: from raw motion-capture quaternions, derives joint angles, ranges of motion, and clearances to grade the seven FMS physical-therapy exercises, scoring form 0–3 with a declarative rule interpreter whose guard operands reject biomechanical compensations.

Python · XSens MVNX · NumPy · quaternion kinematics
