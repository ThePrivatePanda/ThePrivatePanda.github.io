Featured project

MSPoker in active build

solo · design + implementation · Rust + Python

Heads-up poker is effectively solved; multiplayer poker is not. MSPoker studies the open coalition version of the problem: one agent controls several seats at a table and plays them as a single joint player that provably weakly dominates the same seats playing independently.

  • Rust game engine (PyO3) with integer chip accounting and chip-conservation invariants.
  • A 1.4M-parameter seat-attention network trained as a DREAM/CFR blueprint, fine-tuned with KL-anchored PPO.
  • Real-time CFR+ search with a coalition range gadget that computes team counterfactual values jointly.
  • Built spec-first against about 155 verifiable tasks, with human-signed phase gates.
