DetSite — AFROTC Detachment 520

solo · complete · pending command approval

The public website for AFROTC Detachment 520 at Cornell, built page-by-page to the official Air Force compliance checklist.

Overview

A finished multi-page website for the detachment — home, program, heritage, admissions, cadet life, and cadre pages — built as a static HTML/CSS/JS site on GitHub Pages. The whole build was driven by the official Air Force public-website quality checklist (AF IMT 2519 / AFI 35-101). Complete, and pending commander and public-affairs approval before it goes active.

Design decisions 02

  • The site was built against the official compliance checklist from the first page — required .mil links, privacy and security banners, no cadet PII, cadet-only pages password-protected — so it can pass command and public-affairs review rather than needing a rework.
  • A static site on GitHub Pages with a custom domain, because a detachment needs zero-maintenance, low-cost hosting it can own and hand off — not a server someone has to keep running.
